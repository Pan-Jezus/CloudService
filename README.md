# CloudService — SaaS Platform

## Описание проекта
Облачная платформа для надежного хранения данных и автоматизации бизнес-процессов (Вариант 14).

## Технологии
* **Frontend:** HTML5, CSS3, JavaScript
* **Окружение:** Node.js, npm, VS Code
* **Контроль версий:** Git, GitHub
* **Проектирование:** Figma
